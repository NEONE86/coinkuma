# ONE prospective decision evidence v1 — offline-integrated, model calls OFF

Status: implementation of the *evidence contract* from
`PROSPECTIVE_AI_DECISION_LOGGING_DESIGN.md`.  This is a **code-only draft**;
no model client, Bybit collector, scheduler, deployment or order router is
started.  The completed November 3–4 Bybit dataset predates this recorder:
inference applied to it is **RETROSPECTIVE**, even if an offline replay succeeds.

## Scope and fixed comparison

- Register immutable run/policy/model/prompt identities before the first input.
- Policies: `CASH` (no exposure), `PRICE_ONLY` (pinned existing
  `MomentumPlanner`, version `momentum-v1`), `AI_ECON` (market/economic evidence)
  and `AI_MEMORY` (same evidence plus *already matured* previous outcomes).
- The source is an existing, separately audited Bybit public L1 capture stream.
  Every frozen input includes canonical `Frame` payload and hash, raw receipt sequence/hash/
  arrival, source cutoff and memory maturity timestamps. `LIVE_PUBLIC` audits
  require the complete original `raw.jsonl`, `frames.jsonl`, `events.jsonl`.
- Model requests must start no more than **5 seconds after the source frame's
  recorded receipt**, checked independently. Slower inputs are rejected instead
  of silently converting stale information into a current prediction.
- Fix the existing PAPER `Protocol` at 10,000 USDT per independent arm,
  2-second minimum delay, 10 bps/side fee, 5 bps/side modeled slippage,
  1% visible-book participation, 12.5% maximum single-position equity,
  40% exposure, 15% drawdown halt and 3,600-second independent label horizon.
  No leverage or exchange credentials in this experiment.
- Proposed *future* model budgets, not an execution authorization: at most
  **10 calls and 1.00 USDT of declared model cost per arm per finite pilot**;
  per-request reserved charge, actual charged cost and failed-attempt costs
  are separately recorded. The cost must be represented as a decimal string,
  never silently assumed zero or inferred from token counts.
- This draft does not set a real AI model provider or enable real calls.
  `EvidenceRecorder` defaults to `model_calls_authorized=False`, which refuses
  a model request. Operators must obtain a separate authorization and pin the
  actual model, prompt SHA256, provider usage accounting and cost budget.

## Three reusable modules

1. `one_trading.ai_native.prospective_evidence.EvidenceRecorder`: exclusive
   private JSONL file, hash chain, fsync per event, UTC + monotonic times.
   Its methods freeze source input, record request/response/failure, validate
   proposals and close with a cost/unresolved summary. It has no network calls.
2. `one_trading.ai_native.prospective_audit`: independent chronology and
   per-policy budget verifier, importing neither producer nor model client.
   `LIVE_PUBLIC` verification binds frozen frames and raw receipts to source
   files and runs the existing independent `bybit_audit` first.
3. `one_trading.ai_native.prospective_paper`: read-only bridge to the *existing*
   `Experiment`/`Protocol`, followed by the *existing independent PAPER audit*.
   Its recorded-model adapter uses actual proposal-validation latency and
   permits only later-quote conditional fills; it never creates an order.

The evidence journal explicitly does **not** accept caller-supplied PAPER
`fill` events. They are generated by the existing risk/settlement engine
and checked by its independent auditor.

## Offline usage

Smoke test, with no network or external paid model:

```sh
python -m unittest discover -s tests -p test_prospective_evidence.py -v
```

After a separate approved, future source-and-model run writes a private journal:

```sh
python -m one_trading.ai_native.prospective_audit --ledger /private/decision-events.jsonl --source-dir /private/actual-bybit-run
python -m one_trading.ai_native.prospective_paper --ledger /private/decision-events.jsonl --source-dir /private/actual-bybit-run
```

For synthetic tests omit `--source-dir`; that result cannot establish live
provenance. Missing `--source-dir` for `LIVE_PUBLIC` is a hard audit error.
The writer requires a preexisting private parent directory, refuses an
existing target and never resumes or overwrites a journal. Do not put original
source, prompts, model outputs, or any runtime ledger in a public PR.

## Negative controls

Tests require rejection of rehashed future source data, duplicate requests,
backdated responses, late responses masquerading as actionable proposals,
missing failed-attempt costs, immature learned memories, modified policy
versions, unauthorized model attempts and fabricated paper fills.  Valid
offline replay tests later-receipt conditional PAPER fill and cost adjustment.

## Limits and next gate

This first increment **does not** contain a live streaming input adapter or
model-provider client. It proves that independently supplied event records can
be validated and passed into existing PAPER accounting. The standalone future
runtime, provider cost receipts, hard model-call budget, interruption/recovery
semantics, model latency under load and unattended source sync require their
own reviewed and explicitly authorized pilot.

Even an entirely rehashed journal cannot cryptographically prove its wall-clock
timestamps without an independent contemporaneous witness. The Bybit source
file binding authenticates *reference consistency*, not that a model answered
before the market moved. A future economic trial must anchor request/response
times to separate provider receipts and immutable external timestamps.

PAPER bridge deducts recorded model cost as a *post-hoc adjustment* rather than
debiting it from cash before position sizing. Its `cost_adjusted_pnl_usdt` is
an exploratory diagnostic, **not** proof of net forward alpha. Economic
acceptance requires actual prospective responses, provider-backed costs,
independent fills, frozen controls, exposure-adjusted returns and drawdown.
