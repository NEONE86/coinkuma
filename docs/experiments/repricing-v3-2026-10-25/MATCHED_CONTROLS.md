# MATCHED_CONTROLS

180일2배에 성공한 비중복 앵커 890개 중 643개에 실패 대조군 1800개를 연결했다. 같은 UTC 날짜, 거래대금 구간, 연속 이력 구간 안에서 최대3개를 선택하고 날짜 내 재사용을 금지했다. 미매칭 성공도 버리지 않는다.

시간 반기 군집과 심볼 군집을 각각2,000회 재표집한 구간의 합집합을 표시했다. 두 군집축을 완전히 동시에 모델링한 신뢰구간은 아니며, 적은 국면 수와 잔여 종목 상관을 해결하지 못한다. 매칭된 비교는 인과 효과가 아니고, 사례·대조군의 반복 사용이 여러 날짜에 걸쳐 독립성을 만들지 않는다.

**희소 표본의 한계:** 사전 고정된 앵커 날짜에는 compression 신호가0개이므로 조건부확률을 추정하지 못한다. 실제 가설별 사건은 별도로 아틀라스에 모두 보고하고, 유리한 신호를 잡으려고 앵커를 사후 변경하지 않았다. 성공0건 또는 전부 성공인 셀에서 비모수 재표집 구간은 [0,0] 또는 [1,1]로 퇴화할 수 있다. 이는 실제 성공확률이0 또는1이라는 확신을 뜻하지 않으며, 해당 경계 구간은 불확실성의 유효한 상한·하한으로 사용하지 않는다. 연구 우위 판정은 이 확률표가 아닌 고정된 계좌·대조군 게이트를 따른다.
