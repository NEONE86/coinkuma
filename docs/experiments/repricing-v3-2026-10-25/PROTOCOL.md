# PROTOCOL

사전 고정 원문은 [protocol.json](protocol.json), 코드 해시는 [freeze.json](freeze.json)이다.

로컬 사전 규칙 커밋 `affc281`, 코드·검증 동결 `3f7fcc1`. GitHub 게시 커밋은 각각 `4693702`, `de14cc3`이며 대응 Git tree가 동일함을 검사했다. 서버 게시 시각과 로컬 연구 시작 시각을 혼동하지 않는다. 전체 실행 manifest에 원본 SHA와 실행 시작 시각을 보존한다.

두 가설과 가격 대조군만 평가했으며 경험적 파라미터 탐색0회, 사후 성과 맞춤 규칙 변경0회다. 원본 감사 저장의 cp949 오류 후 UTF-8 옵션으로 동일 코드 재실행한 기록은 [연구 기록](../../REPRICING_V3_WORKLOG.md)에 있다. 기존 브로커와 계좌 엔진은 수정하지 않았다.

비용은 편도 기본 수수료10bp+슬리피지10bp, 스트레스20bp+30bp. 현물 무차입이므로 펀딩0. D완료 후 D+2시가보다 빠른 체결은 없다. 진입 이후 달력구간의 결측은 보수적인 전액 상각을 사용한다. 주문장·부분체결·거래소 주문 필터·시가 유동성은 검증되지 않았고, 일봉 존재가 실제 체결을 보장하지 않는다.

연구상 우위와 실거래 관련성의 모든 게이트는 JSON에 고정되어 있다. 연구 우위를 통과해도 실거래 승인으로 보지 않는다. 실패 가설은 REJECT, 성과 실패 없이 표본·필수 감사만 부족한 경우 NEEDS_MORE_EVIDENCE다. 이전 구간을 완전히 미관측된 OOS라고 부르지 않는다.
