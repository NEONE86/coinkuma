## 시점 정합성 결론

OI CSV의 `create_time`은 관측 기록 시각이다. 이 값을 공개·가용 시각으로 바꾸지 않았다. `LastModified`는 현재 보관 객체의 갱신 시각이며, **최초 공개시각과 동일하다고 입증하지 못했다.** 일부 과거 OI 객체는 관측 후 수년 뒤 갱신됐다. 이것이 최초 공개가 그때까지 지연됐다는 뜻도 아니고, 지금 보이는 값이 당시와 같다는 증거도 아니다.

[Binance OI 공식 문서](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data)는 timestamp를 기간 종료시각으로 설명하고 REST 이력의 최근 1개월 제한을 명시한다. 연결된 Binance 도구에서 실제 2022-01-01 OI 요청은 `startTime` 오류로 거부됐다. 최신 OI 3개는 반환됐지만 역사적 공개시각 필드는 없다. 해당 정상 응답을 과거 전체로 소급하지 않았다.

펀딩 원문에는 정산시각·간격·확정율이 있지만 정산 마크가격이 없다. BTC 2022-01-01 공식 API 표본 3건의 `markPrice`도 빈 값이었다. 펀딩 기록 5,880건은 정시에서 밀리초 차이가 있어 내림하지 않고 유지했다. 시간봉 시가를 정확한 정산 마크로 바꾸거나 펀딩을 0원으로 가정하지 않았다. 이 표본이 모든 기간의 API 마크가 없음을 증명하는 것은 아니며, 완전한 정산 자료를 확보하지 못했다는 한계다.

과거 계약·필터·종료 조건·유지증거금 이력도 충분히 확보하지 못했다. 현재 주요 계약의 정보만으로 과거 선물 조건을 인증하지 않는다. 이 단계에서 무리하게 현물 브로커를 선물 계좌로 재사용하지 않았다.

개발 2022~2023, 검증 2024, 도전 2025~2026년 9월을 고정했다. 과거 큰 시장 구간은 앞선 실험에서 이미 관찰해 미관측 OOS라고 부르지 않는다. 전체 선물 자산회계·체결·마진·강제청산 엔진, 가격 중심/무작위 대조군은 데이터 게이트 통과 전 보류했다.
