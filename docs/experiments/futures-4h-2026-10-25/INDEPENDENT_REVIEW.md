# 선물 4시간봉 — 독립 데이터 재현 검토

**NEEDS_MORE_EVIDENCE. 성과 백테스트 미실시.**

## 실제 독립 계산

`scripts/validate_futures_4h.py`는 전략 데이터 파서인 `parse_row`, `inspect_zip`, `aggregate`를 가져오지 않는다. 별도 CSV/ZIP 파서와 시각별 그룹으로 원시 HTTP 캐시를 다시 읽었다. 동일 작성자의 별도 프로그램이며 외부기관 감사나 전략 성과의 독립 검증과는 구분한다.

1. 목록 XML 17개와 ZIP 4,416개 및 모든 CHECKSUM을 재검사했다. 캐시 원문 SHA-256·URL·공급자 파일명, S3 객체 수정시각·파일 크기를 대조했다.
2. 원시 1,466,397개 행을 독립적으로 해석했다. 헤더 유무, UTC 시각, 시간 단위, OHLC 유효성, OI의 유한·비음수 값, 펀딩의 실제 밀리초·간격을 확인했다. 헤더 없는 과거 가격 파일의 첫 행도 보존했다.
3. 동일 중복 40,152행·순서 역전 11,238건·상충 시각 0개와 고유 비상충 기록 1,426,245개가 일치했다. 잘못된 값은 보간하거나 0으로 채우지 않는다. 같은 시각에 서로 다른 값이 있으면 양쪽 모두 격리하는 동작은 합성 회귀 테스트로 확인했다.
4. 원시 소스 목록 루트 `59732404...3196666`, 정규화 목록 루트 `786572ab...bb8bf5`가 주 감사와 정확히 일치했다. 숫자 자체를 공개 파일에 넣지 않고 원문 캐시와 해시로 재현할 수 있게 했다.
5. 평가 예정 구간의 완성 4시간 체결가격 격자는 BTC·ETH 각각 10,404개다. 2025-01-01 이후 가격 시각을 제거한 과거 격자는 각각 6,576개로 일치했다. 이는 데이터 달력 검증이다. 미실행 전략의 체결·자산 불변성을 검증했다고 표현하지 않는다.
6. OI 원문 헤더에서 과거 공개/가용시각 필드는 발견되지 않았다. `create_time`, 현재 수집시각, `LastModified`를 사용 가능한 과거 정보시각으로 꾸미지 않았다. 검증된 OI 가용 관측 0개와 주 게이트의 NEEDS_MORE_EVIDENCE 판정이 재현됐다.
7. 미실시 전략의 수익률·PF·거래 수·월별 손익을 `null`로 둔 것도 확인했다. flat 0% 성과, 가상의 실현 펀딩 비용이나 대조군 결과는 없다.

## 남은 필수 작업

- 원래 가용/수신시각이 입증되는 연속 OI와 시장구조 이력, 변경 이력 및 시점별 소스 버전 확보.
- 정산 마크와 실제 펀딩 사건 대조. 정시 ±밀리초를 임의 반올림해 포지션의 과금 여부를 바꾸지 않을 것.
- 제한된 BTC·ETH 범위에서라도 충분한 과거 계약 동일성·필터·유지증거금·종료 조건 검증. 현재 종목 상태는 과거 시장 구조의 완전한 기록이 아님.
- 위 데이터 자격 충족 후 완전한 선물 계좌·현금담보·체결·마진·갭/강제청산 엔진 구현, 단일 고정 정책의 기본/스트레스 실데이터 성과와 독립 자산회계 재현, 대조군·시기 안정성 검사.
- 이후 새로 시작하는 주문 없는 전방 운영 증거. 장중 위험 제한을 실제로 지킨 결과는 이번 단계에 없음.

OI를 임의로 4시간 또는 하루 늦추는 것만으로 과거 공개시각을 입증할 수는 없다. 그런 가정의 진단 실험이 필요하다면 별도 버전으로 고정하고 검증된 PIT 성과와 구분해야 한다. 이번에는 수익 숫자를 만들기 위해 데이터 게이트를 완화하지 않았다.

[independent.json](independent.json)은 실제 재현 집계다. 테스트 172개는 합성 소프트웨어 검사이며 수익성 증거가 아니다. 기존 v1/v2 기각 보고서·데이터와 기존 PR은 변경하지 않았다.
