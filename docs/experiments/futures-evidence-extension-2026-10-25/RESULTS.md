# 선물 4시간봉 추가 증거 확보·데이터 게이트 재검증

**판정: NEEDS_MORE_EVIDENCE. 데이터 출처 후보의 실재와 일부 과거 수신시각·정산 마크는 추가 확인했지만, 고정 평가 구간 전체의 자료 자격은 충족하지 못했다. 전략 수익 백테스트와 성과 독립 재현은 미실시다.**

## 출발점과 사전 기준

PR #5 실제 HEAD `152ae3635527378e02d9de138535e3538b4ae5ec`에서 `research/futures-evidence-gate-20261025`를 만들었다. 기존 PR과 모든 기존 추적 파일을 변경하지 않았다. [추가 확보 계획](../../FUTURES_EVIDENCE_EXTENSION_PLAN.json)을 로컬 커밋 `eec21e3`에 먼저 고정한 뒤 표본을 수집했다. 원래 [전략 프로토콜](../../FUTURES_4H_PROTOCOL.json), 비용, 2022-01-01~2026-10-01 미만 평가 구간은 그대로다. 성과를 보거나 사후 규칙을 조정하지 않았다.

Tardis 무료 표본은 2022-01-01·2024-01-01·2026-09-01의 BTCUSDT/ETHUSDT다. 일간 derivative_ticker 6개와 각 날짜 00:00·12:00 원시 openInterest 1분 구간 12개를 확보했다. Binance 펀딩 API는 두 계약 각각 2022~2026년 1월 1일과 2026년 9월 1일을 조회했다. 시장 수익에 따른 표본 선택이 아니다. 두 주요 계약만의 제한된 감사로, 거래소 전체 종목의 생존자 편향 제거를 입증하지 않는다.

## OI 가용시각: 추가 확보는 성공, 연속 자격은 미달

| 실제 확보한 항목 | 결과 | 의미 |
|---|---:|---|
| 일간 derivative_ticker 파일 | 6개 | 공급자 수신시각이 있는 정규화 자료 |
| ticker 전체 행 | 817,848 | 개별 행이 독립 OI 관측이라는 뜻은 아님 |
| 원시 OI 1분 응답 | 12개 구간 | 공급자 원문 형식의 거래소 응답 |
| 원시 OI 응답 메시지 | 68건 | 거래소 `data.time`과 공급자 수신 접두시각 동시 확인 |
| 원시 표본의 음수 수신 지연 | 0건 | 해당 표본 내부 시계 정합성 진단 |
| 원시 표본의 관측→수신 지연 | 약 1.88~26.81초 | 통신 지연만이 아니라 거래소 관측 경과·폴링을 포함 |
| 고정 평가 달력 | 종목당 1,734일 | ticker 표본은 종목당 3일에 불과 |
| 연속 자료로 자격을 입증한 전략 관측 | 0개 | 이전 24시간 OI와 전체 구조 자료도 필요 |

[Tardis의 Binance 수집 설명](https://docs.tardis.dev/historical-data-details/binance-futures)은 OI를 REST로 수집해 generated 채널에 저장한다고 설명한다. 실제 원시 응답의 `generated=true`, 거래소 `time`, 공급자 접두 수신시각을 확인했다. 수신시각은 **공급자가 보고한 과거 수신 기록**이며, 거래소 최초 공개시각이나 암호학적으로 인증된 당시 기록이라고 단정하지 않는다. 현재 다운로드 시각·파일 수정시각을 과거 수신시각으로 바꾸지 않았다.

[정규화 스키마](https://docs.tardis.dev/downloadable-csv-files/data-types)는 ticker의 수신시각과 예상 펀딩을 설명한다. [현재 공급자 매퍼](https://github.com/tardis-dev/tardis-node/blob/master/src/mappers/binance.ts)는 마크·체결·OI 상태를 합친다. 실제 CSV에서 같은 OI 값이 반복되는 행이 다수 확인됐다. 행의 `timestamp`를 OI 고유 갱신시각으로 사용하거나, OI 값이 그대로인 것을 새 응답의 부재로 간주하면 안 된다. 현재 매퍼가 과거 파일 생성 당시의 버전과 같다는 증거도 확보하지 못했다. 원시 OI와 정확한 버전 매핑이 필요하다.

[공개 접근 범위](https://docs.tardis.dev/downloadable-csv-files)는 매월 1일 샘플이다. 샘플이 있다는 사실을 수년간의 연속 자료를 확보했다는 뜻으로 확대하지 않았다. 유료 구독·구매·계정 접근은 하지 않았다. 원시 요청의 최초 406은 문서상 필수 gzip 헤더 누락 때문이었고, 해당 응답을 별도 캐시에 보존한 뒤 올바른 요청으로 성공했다. 최종 `sources.json`은 정상 형식 요청과 문서 조회 26건을 기록한다.

## 펀딩 정산 마크: 일부 기간에서 실제 추가 확보

| API 표본일 | 계약별 사건 수 | 양 계약 합계 마크 확보 | 기존 ZIP과 정확한 시각·정산율 대조 |
|---|---:|---:|---|
| 2022-01-01 | 각 3 | 0/6 | 6/6 일치 |
| 2023-01-01 | 각 3 | 0/6 | 6/6 일치 |
| 2024-01-01 | 각 3 | 6/6 | 6/6 일치 |
| 2025-01-01 | 각 3 | 6/6 | 6/6 일치 |
| 2026-01-01 | 각 3 | 6/6 | 6/6 일치 |
| 2026-09-01 | 각 3 | 6/6 | 6/6 일치 |
| 합계 | 36 | **24/36** | **36/36 일치** |

연결된 Binance 읽기 전용 API의 정규화 응답을 별도 저장했다. `fundingTime`의 밀리초를 그대로 사용하고 정산율은 Decimal로 기존 공식 ZIP과 비교했다. API 자료는 현재 조회된 과거 정산 값이다. 그 값의 역사적 공개시각까지 입증한 것은 아니다. 24개의 양수 마크를 확보했지만, 12개 빈 마크와 조회하지 않은 날짜를 보간하지 않았다. 시간봉 마크를 정산 마크로 대입하지 않았다. 모든 옛 기록의 마크가 없다는 결론도 아니다.

Binance 커넥터 응답 해시는 **MCP 정규화 결과의 해시**다. 공급자 원래 HTTP 바이트라고 표현하지 않으며, 도구 호출 전후 현재 시각을 과거 가용시각으로 쓰지 않는다. 공개 `funding_samples.json`에는 표본·요청·일치 건수·기존 ZIP 해시만 담고 실제 가격·OI 관측 행은 Git에 올리지 않았다.

## 계약 조건: 공식 변경 사건은 확인, 전체 이력은 미확보

[Binance의 2024-05-28 변경 공지](https://www.binance.com/en/support/announcement/detail/aa735cd2d8bd4e7bb092179cf086e486)는 BTCUSDT·ETHUSDT USD-M **무기한**의 증거다. 2024-05-27 게시, 다음 날 10:30 UTC 적용 개시와 약 30분의 변경 창, 기존 포지션 비영향 조건을 확인했다. 낮은 명목 구간의 유지증거금률은 전후 0.4%로 표시돼 있다. 이 한 사건만으로 2022~2026년의 모든 조건을 채우지는 않았다. 기간물·COIN-M 공지를 이 계약에 적용하지 않는다.

직접 HTTP 수집은 두 공식 공지에서 202·빈 본문을 반환했다. 이를 성공한 문서 원문 확보로 집계하지 않았다. 위 5월 공지는 웹 도구에서 읽은 추출물을 별도로 보존·해시했고, **원래 HTTP 응답이 아닌 웹 추출물**임을 명시했다. 변경 전후 표와 grandfather 조건의 수동 해석은 외부기관이 인증한 것이 아니다. 1월 공지는 검색에서 발견했지만 페이지 경로가 목록으로 이동하는 등 안정적인 원문 확보가 부족해 완전한 조건 원장으로 채택하지 않았다.

[Tardis 메타데이터 문서](https://docs.tardis.dev/api/instruments-metadata-api)는 인증된 구독 접근과 변경 이력의 한계도 설명한다. 비계약승수 변경은 best effort여서 구매만으로 틱·수량·마진 이력 전체가 자동으로 입증되는 것도 아니다. 현재 exchangeInfo나 하나의 공지로 미확인 기간을 채우지 않았다.

## 재검증·독립 재현·성과 상태

`decision.json`의 사유는 BTC/ETH 각각의 연속 OI 수신 이력 및 정확한 정산 마크 부족, 전체 유효시점 계약 조건 부족, 시장구조 입력의 역사적 가용시각 부족이다. 이 구현은 추가 표본의 자격을 심사하며 완전한 자료를 인증하는 어댑터가 아니다. 자료를 모두 확보하면 그 범위를 검사하는 새 어댑터와 추가 검증이 필요하다. 이미 발견한 누락을 무시하거나 통과를 위해 기간을 축소하지 않았다.

별도 프로세스·별도 원시 파서가 26개 소스 바이트/상태, ticker 817,848행, 원시 OI 68건의 시각·지연, 펀딩 36건의 정산율·밀리초 및 마크 24/12건을 재계산했다. 같은 NEEDS_MORE_EVIDENCE를 재현했다. 동일 작성자의 별도 구현이며 외부 제3자의 감사가 아니다. 공식 공지의 수동 해석을 역사적 인증으로 검증했다는 주장도 아니다. 테스트 **178개**, compileall·CLI 점검이 통과했다.

누적수익률·CAGR·MDD·PF·승률·거래 횟수·평균 보유기간·자본 투입률·월간 분포·최악 연속손실·월별 원화 손익·목표 달성 빈도는 모두 **미측정**이다. `performance_metrics=null`이며 평평한 0% 곡선도 만들지 않았다. **전략 백테스트·성과 독립 재현·대조군은 미실시**다. 자본 2,000만 원의 월 현금흐름 목표를 뒷받침할 새 성과 증거는 없다.

기존 고정 코드 12개 해시와 PR #5의 기존 추적 파일을 보존했다. PR 병합·실주문·레버리지는 실행하지 않았다. [재현 절차와 다음 작업](../../FUTURES_EVIDENCE_EXTENSION.md), [별도 재현 집계](independent.json), [자료별 감사](sources.json), [판정](decision.json)을 참조한다.
