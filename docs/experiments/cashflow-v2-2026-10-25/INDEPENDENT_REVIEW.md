# Cashflow Alpha v2 — 독립 계산 검토

**판정: A REJECT / B REJECT.** 측정된 스트레스 성과가 사전 기준에 미달한다. 표본·계산 검증의 통과가 이 판정을 PASS로 바꾸지 않는다.

## 실제 수행 범위

전략 실행을 마친 원장을 별도 Python 프로세스 `scripts/validate_cashflow_v2.py`에서 읽었다. 전략의 성과 함수 대신 독립 현금·재고·거래 재구성 함수를 사용했다. 전략과 검증 프로그램을 같은 작성자가 만들었으므로 외부 제3자의 투자감사라고 부르지 않는다.

1. **48개 계좌**: 연속 4개, 연도별 독립 32개, 시기별 독립 12개의 최종 현금·원가·매도 대금·수수료·종료 거래 손익을 대조했다. 매일의 현금과 보유 수량을 원시 종가에 다시 표시하여 보고된 1일 단위 자산과 비교했다.
2. **계산과 위험**: 편도 수수료·슬리피지, 신규 단일 위험 0.5%, 신규 진입 직후 총위험 3%, 신규 비중·총투입 한도, 현금 음수 방지, 추가매수 금지를 원장에서 재계산했다. 거래 개수는 분할 매도 횟수가 아닌 전량 청산까지의 거래 단위다.
3. **실제 시점 규칙**: 과거 일봉에서 유동성 순위·240일 연속 이력·갭·식별 경계를 별도로 재구성했다. 모든 신호일에 후보 집합과 초기 ATR 스톱을 전략 캐시와 별개 계산으로 확인했다. A 연속 계좌는 각각 405일·26,940 종목일, B는 각각 2,832일·188,545 종목일이다. B에는 평가 시작 직전 2일의 지연 계획이 포함된다.
4. **지연·원장 동일성**: 모든 BUY는 선행하는 D+2 계획과 연결되고 새 진입만 존재한다. 모든 실제 체결에는 해당 원시 일봉이 있으며 4개 연속 계좌의 0거래량 일봉 체결은 0건이다. 보유 종목 누락 상각은 이번 연속 계좌에서 0건이었다. 합성 테스트는 누락 시 전액상각 동작도 검증한다.
5. **전체 재현**: 4개 연속 계좌를 새 패널 객체로 다시 실행해 결과 전체가 일치했다.
6. **미래 삭제**: 모든 종목에서 2023-01-01 이후 일봉을 물리적으로 제거하고 다시 실행했다. 과거 자산·체결·상각·계획이 모두 일치했다. 각 조건 1,461일을 확인했고, A 기본/스트레스 각각 4건, B 기본 126건·스트레스 125건의 체결을 포함한다. 잘린 계좌 마지막 날에는 강제청산을 추가하지 않았다.
7. **대조군과 불확실성**: 사전등록 seed 0~199를 두 후보에 각각 적용한 스트레스 대조군 400개를 전부 실행하고 각 최종 원장을 독립 재구성했다. 93개월을 3개월 블록으로 4,000회 재표본 추출했다. 전체 일별·후보 규칙 검사는 주 전략 48개 계좌에 적용했고, 대조군 400개에는 동일 실행 엔진과 독립 최종 원장 검사를 적용했다. 대조군 전부의 규칙·일별 재현 검사를 새로 수행했다고 주장하지 않는다.
8. **기존 실험 보존**: 콜백 확장 뒤에도 기본 실행 경로가 유지되는지 실제 같은 데이터로 v1 기본·스트레스를 다시 실행했다. 기존 PR #3의 누적수익률·CAGR·MDD·PF·거래 수·승률·자본 투입률·수수료가 모두 일치했다. [v1_engine_parity.json](v1_engine_parity.json)에 새 회귀 검사의 집계만 저장하고, 기존 실험 파일은 바꾸지 않았다. 이는 추가 후보 실험이 아니다.

## 총위험에 대한 실질적 발견

**3%는 신규 진입 시점의 총위험 제한이다. 상시 총위험 3% 유지 검증은 통과한 것이 아니다.** 독립 계산에서 B 스트레스의 신규 진입 직후 최대 위험은 2.99946%였지만 일별 종가에서 표시가격부터 스톱까지의 총위험은 최대 **5.00658%**였다. A 스트레스도 최대 **3.89092%**였다. 자산가격 변화와 D+2 스톱 조정 사이의 위험 증가를 기존 브로커가 즉시 축소하지 않는다. 이는 고정된 실행 방식의 한계로 보고하며 이번 결과를 바꾸기 위해 사후 수정하지 않았다.

자본 투입·종목별 비중도 매일 변동한다. 신규 진입 한도와 이후 가격 변동에 따른 비중을 구분해야 한다. 실제 운용에 앞서 상시 위험 예산의 정의와 이탈 대응을 별도 사전등록·실행 모델에서 검증해야 한다. 주문장 충격·갭으로 발생하는 초과손실도 별개다.

B의 동시 저가 낙폭 하한은 기본 -15.3449%다. 보호 스톱을 무시하고 모든 포지션이 당일 최저가라고 놓은 진단으로, 실제 동시에 관측되거나 체결된 낙폭이 아니다. 종가 MDD를 장중 최대 손실 보장으로 바꿔 표현하지 않는다.

## 남아 있는 불확실성

- 과거는 v1에서 이미 사용했다. 이번 검증은 미관측 OOS도, 앞으로 수익이 날 확률의 추정도 아니다. 93개월의 블록 재표본은 긴 구조 변화·연구 선택 편향을 포함하지 못한다.
- 저장된 가격은 체크섬·파생 재생성·이전 해시 일치가 확인됐지만, 756개 시장 전체의 공식 상장·폐지 공지·토큰 동일성·과거 데이터 공개 시점을 인증한 기록은 없다. 종료 이력 253개를 유지한 점과 완전한 편향 제거는 다르다.
- 일봉 OHLC에서 실제 시가 주문의 깊이, 스프레드, 체결 순서·부분체결, 최소 주문·호가 단위, 실제 주문 지연·장애를 알 수 없다. D+2와 두 비용 시나리오는 가정이다.
- 상시 총위험 한도, 일중 손실과 중단 체결, 장기 운영 중 중복·장애·예외 대응에 대한 실제 전방 증거가 없다.
- 사용량·수익·토큰 가치귀속·공급 변화·자본 유입의 발표시각 데이터가 없다. 가격 프록시를 저평가의 증거로 취급하지 않는다.
- 무차입 현물 외 선물 펀딩·마크가격·마진·강제청산은 검증하지 않았다. 세금·USDT/KRW·환전 및 인출 비용도 제외했다.
- 외부인이 저장된 DB와 원장을 받아 재현한 독립 감사는 아직 없다. 공개 GitHub CI는 합성 소프트웨어 검사이며 실데이터 성과 검증이 아니다.

수치와 체크 결과는 [independent_validation.json](independent_validation.json), [metrics.json](metrics.json), [decision.json](decision.json)에 보존했다. 실제 주문·실계좌 운영 승인은 없다.
